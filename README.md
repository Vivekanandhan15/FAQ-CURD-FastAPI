# FastAPI FAQ Manager

A simple and efficient FAQ (Frequently Asked Questions) CRUD API built using **FastAPI**, **SQLAlchemy**, **Pydantic**, and **PostgreSQL**.  
This project demonstrates API development, ORM use, environment variables, and clean architecture.

---

## 🚀 Features

- Create new FAQ  
- Read all FAQs  
- Read FAQ by ID  
- Update existing FAQ  
- Delete FAQ  
- SQLAlchemy ORM Integration  
- Environment variables for DB security  
- Automatic table creation
